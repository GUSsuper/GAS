# Luma｜多元生活平台 MVP

面向全體 LGBTQ+ 族群的社群、活動探索與運動揪團平台。此分支先建立可互動的前端原型與產品／技術規格。

## 目前已建立
- [互動式網頁原型](apps/lgbtq-platform/index.html)：響應式版面、活動分類篩選、運動活動捷徑、示範貼文、喜歡與檢舉提示。
- [產品規格](docs/PRD.md)
- [API 草案](docs/API.md)
- [PostgreSQL schema](database/schema.sql)

## 本機預覽
直接以瀏覽器開啟 apps/lgbtq-platform/index.html，或在該目錄執行任何靜態檔案伺服器。

## 重要狀態
目前是前端互動原型，沒有正式登入、伺服器、資料庫連線或真實報名。所有活動為示範資料，貼文只存在目前頁面的記憶體。不可直接當成正式公開服務。

## 建議下一步
1. 確認現有 GAS monorepo 的前端／後端架構並將原型整合進既有 app。
2. 建立 migration、API 與整合測試。
3. 接入成熟身份服務、角色權限、內容審核、檢舉與封鎖。
4. 加入部署流程、監控、備份、隱私政策與無障礙測試。
