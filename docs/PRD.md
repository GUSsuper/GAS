# 多元生活平台（Luma）MVP 產品規格

## 產品願景
服務全體 LGBTQ+ 族群的生活與社群平台，以社群交流、活動參與、運動揪團為第一版核心。

## MVP 範圍
- 首頁與產品導覽
- 社群動態：貼文列表、分類、示範發文
- 活動探索：類別篩選、活動卡片、示範報名
- 運動揪團：運動類型、程度、時間與集合資訊
- 安全中心：隱私原則、檢舉與封鎖流程說明
- 響應式介面、鍵盤操作與可讀對比
- API、資料庫及管理後台規格

## 暫不納入
- 真正的私訊、即時聊天、付款或商城交易
- 未經授權的敏感身分推斷、精確位置追蹤或通訊錄上傳
- 未接後端前，不宣稱報名、貼文或帳號資料已永久儲存

## 網站地圖
首頁、社群、活動探索、運動揪團、安全與隱私、個人設定、主辦者中心、管理後台。當前以單頁互動原型呈現，並非所有路由均已部署。

## 核心流程
活動：探索 → 類別篩選 → 查看詳情 → 報名確認。社群：動態 → 分類 → 閱讀 → 發文。運動：選類型 → 查看時間／程度／名額 → 參加。

## 成功指標
活動卡片點擊率、報名完成率、每週活躍與四週回訪、貼文互動率、檢舉處理時間、無障礙缺陷與隱私事件數。

## 隱私與安全
- 性傾向與性別認同屬敏感資訊，預設不要求填寫。
- 支援暱稱、個人檔案可見性控制、封鎖、檢舉、帳號刪除及資料匯出。
- 不公開參與者名單，除非使用者明確同意並可撤回。
- 不預設使用精確定位；敏感資料採最小化蒐集與限期保存。
- 使用成熟身份服務、伺服器端授權、速率限制、輸入驗證、稽核與備份。
- 上線前由熟悉台灣個資法及相關法規的人員檢視政策與流程。

## 技術原則
前後端分離、版本化 API、PostgreSQL、先做 PWA／響應式網站，再依使用證據評估原生 APP。影音採物件儲存與 CDN。AI 服務可替換，敏感內容不預設送往模型。

## 正式上線門檻
完成登入與授權、資料庫遷移、伺服器端驗證、反垃圾、內容審核、隱私政策、服務條款、備份、監控、無障礙及安全測試。
